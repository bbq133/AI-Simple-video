# Learned Rules

Read this file before every production run. Add reusable user feedback here after applying it to the current deliverable.

## Visual direction

1. Prefer a fresh paper-cut sketch look over generic flat MG.
2. Warm ivory + pale mint + charcoal + restrained coral is the locked default palette.
3. Keep the result attractive and light, but not childish or overly decorative.
4. Use 9:16 for this short-form video workflow.

## Composition

1. Large blank areas in a settled frame are a defect when they do not guide focus or reserve a deliberate motion path.
2. Judge the **completed frame**, not only individual component beauty.
3. Balance content vertically: label, main visual, supporting modules, and summary should form one reading path.
4. Summary text should belong to the composition rather than look stranded near the bottom.
5. Review at 360 px width because desktop-sized previews hide hierarchy and readability problems.

## Motion

1. Do not reveal the entire card at once.
2. Reveal components in the same order as the spoken phrases.
3. Opening sequence example:
   `01 label → character/? → AI → 大模型 → 风口 → summary`.
4. Build independent layers from HTML, SVG, or transparent PNG; do not cover flattened content with duplicate chips.
5. A settled frame must show all components clearly without overlap.

## Transitions

1. Fast page turns feel uncomfortable.
2. Use: complete scene → fade out → logical bridge → fade in.
3. Bridge titles belong in the normal central visual area, not as tiny bottom text.
4. Use hierarchy: stage kicker / large focus title / quiet preview hint.

## Narration

1. Approve the script before generating audio.
2. Warm does not mean slow. Avoid over-slow delivery.
3. Avoid broadcast cadence, over-regular pauses, and synthetic emphasis.
4. On-screen `AI` is spoken as `人工智能` by default.
5. Generate a short voice sample before rerendering the full video after voice changes.
6. Derive picture durations from measured audio, not guessed timings.

## Preview and delivery

1. Large MP4 files and GitHub blob pages are unreliable as in-chat review.
2. Send compressed JPEG/GIF first; preserve full-resolution masters in the repository.
3. Mobile MP4 needs faststart and compatible H.264/AAC settings.
4. Always provide a progressive reveal strip to show component order without video playback.

## Skill maintenance

After a reusable correction:

- fix the current work;
- add the generalized rule here;
- update `SKILL.md` if the default or hard gate changed;
- add a dated `CHANGELOG.md` entry;
- commit the skill update together with the corrected deliverable.
