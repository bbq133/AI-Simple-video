## 1.0.0 — 2026-07-18

Initial workflow distilled from iterative production feedback:

- lock fresh paper-cut sketch as the default direction;
- require 9:16, compressed previews, and mobile-compatible delivery;
- add script-approval and voice-sample gates;
- map component entrances to spoken phrases;
- replace whole-card reveals with progressive focus;
- replace fast page turns with fade/bridge/fade transitions;
- prohibit tiny bottom bridge captions;
- prohibit obscuring overlays;
- pronounce on-screen `AI` as spoken `人工智能` by default;
- add a hard settled-frame check for meaningless blank space;
- define a feedback loop that updates the skill after reusable corrections.
